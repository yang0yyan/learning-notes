## Java 技术内容

- JavaSE：Java 标准版 Java Standard Edition
- JavaEE：Java 企业版 Java Enterprise Edition

## 安装、配置JDK

安装jdk8,并配置环境变量

## Java程序开发步骤

- 编写 .java 文件，通过编译器编译成 .class 文件（字节码文件），然后在 jvm（java 虚拟机）上运行
- jvm：将字节码翻译成计算机可以读懂的代码
- 创建.java文件编写程序，使用javac命令编译，使用java命令执行
  - javac ./Hello.java  // 包含后缀
  - java Hello  // 不用写后缀
