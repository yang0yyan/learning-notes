# 多态

## 1、多态的应用场景

Java中类型分类：

- 基本类型
  - 整型：byte、short、int、long
  - 浮点型：float、double
  - 字符型：char
  - 布尔型：boolean
- 引用类型：字符串、数组、自定义类

注意：类型的不同决定了在内存上占用空间的不同。基本类型都保存在栈上，引用类型在栈和堆上都有。

**多态的定义：**

- **多态（Polymorphism）**是面向对象程序设计的三大特性之一

- 同一行为在不同对象上表现出不同的执行效果
- 父类引用指向子类对象，在执行方法时，调用的是子类的实现。

**多态成立的三个必要条件：**

- 子类继承父类或实现接口
- 子类对父类方法进行重新实现
- 父类引用指向子类对象

**多态带来的意义：**

- 解耦：调用者无需关心对象实际类型
- 扩展性强：新增子类无需修改原有代码
- 增强灵活性：可以统一处理不同类型对象



## 2、父类和子类的互转

**向上转型（子类 → 父类）✔安全**

```java
Cat cat = new Cat();
Animal animal = cat;   // 向上转型
```

- 自动完成（无需强制转换）
- 转型后**只能访问父类中定义的成员**（但调用方法仍走子类的实现 → 多态）

**向下转型（父类 → 子类）⚠有风险**

```java
Animal animal = new Cat();
Cat cat = (Cat) animal;  // 向下转型
```

- **需要强制类型转换**
- **不一定安全**，如果对象真实类型不是 Cat → 会抛出 `ClassCastException`

**向下转型正确的判断方式**

强转前应先用 `instanceof` 进行类型检查：

```java
if (animal instanceof Cat) {
    Cat cat = (Cat) animal;
    cat.meow();
}
```

注意：向上转型后丢失的能力，向下转型才能取回



## 3、父类作为参数实现多态

```java
void doAction(Animal animal) {
    animal.action();
}
```



## 4、父类作为返回值实现多态

```java
Animal createAnimal(String type) {
    if (type.equals("cat")) return new Cat();
    if (type.equals("dog")) return new Dog();
    return new Animal(); // 或抛异常
}
```
